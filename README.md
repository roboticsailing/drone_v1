# Components for a small sailing drone (version 1)

This repository contains files to build a small sailing drone. The basic 3D printable shapes are provided as zipped STEP files. Note, that the hull can be printed on an FDM printer using, e.g., PETG in spiral vase mode, while all other 3D components could be printed on a resin printer. Also, the gears to move the rudders come in different sizes, as different resins shrink differently. The inner and outer frames as well as the hatch are provided as SVG files and should be cut on a milling machine. We use 3 mm, 2 mm, and 1 mm glass-reinforced epoxy laminate for inner frame, outer frame, and hatch, respectively.

We plan to eventually make more components and instructions available.
