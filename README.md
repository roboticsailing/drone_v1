# small-sailing-drone

This repository contains files to build a small sailing drone. The basic 3D printable shapes are provided as zipped STEP files. Note, that the hull can be printed on an FDM printer using, e.g., PETG in spiral vase mode, while all other 3D components could be printed on a resin printer. also, the gears to move the rudders come in different sizes, as different resins shrink differently. The frame is provided as a SVG file and should be cut on a milling machine out of, e.g., 2 mm glass-reinforced epoxy laminate. It serves to stabilize the deck.

We plan to eventually make more components and instructions available.
